# Mini Portal de Colombia con API

## Descripción
Página web sobre Colombia que usa la información de la [API Colombia](https://api-colombia.com/). Tiene cuatro páginas:

- **Inicio:** presenta el menu y tiene los enlaces a las otras secciones.
- **Turismo:** muestra 20 lugares turísticos en un mapa y en tarjetas.
- **Platos típicos:** muestra los platos de cada región con su descripción e imagen.
- **Detalles:** puse un mapa interactivo usando una api, al hacer clic en una tarjeta, muestra toda la información de ese lugar o plato.


## Tecnologías usadas
- HTML5
- CSS
- JavaScript 
- [Leaflet](https://leafletjs.com/) para el mapa interactivo
- [API Colombia](https://api-colombia.com/)
- Git y GitHub

## Instrucciones de uso
1. Clonar el repositorio:
   git clone https://github.com/samid1097-tech/samid-plata-api-colombia..git
2. Abrir `index.html` en el navegador, o usar la extensión **Live Server** de VS Code.
3. Navegar en la pagina
